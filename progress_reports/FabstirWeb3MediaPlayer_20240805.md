## Fabstir Media Player #2 - Progress Report #4

### What progress was made on your grant this month?

- Added new standard for semi-fungible NFT nestable structures for the use case of video series and box sets
- Fixed the import of nestable structure of encrypted media to new owner account
- Fixed issue with audio player and scrolling lyrics
- Added support for multiple subtitles selectable from player cc menu
- Added support for multiple audio channels for e.g. foreign language dubbed tracks
- Added support for credits system that includes listing departments and people with individual credits attributes
- Added NFT permissions page to allow creators to specify which NFT markets to enter and under what royalty rates

### Summarize any problems that you ran into this month and how you'll be solving them.

- Fabstir Media Player has a lot of features so initial release will be for invite only to catch any early issues
- Will temporarily remove MetaMask Snaps features from a production version as audit and Consensys approval required that can be done later
